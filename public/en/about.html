Our release standard

We check the core path from input through processing and download, and provide actionable messages when a task fails. File formats and browsers differ, so we document what a tool does and where it has limits instead of promising a perfect result. Important originals should be kept and every output reviewed.

Editorial policy

Our guides are based on implemented behavior, hands-on checks and common failure cases—not generic summaries. When an implementation changes, we review related explanations. For official applications, tax and legal matters, we direct readers to verify current requirements with the receiving authority or a qualified professional.

Privacy and advertising

Image and PDF conversion normally happens inside the browser, and the file itself is not sent to a SunData server. Anonymous reaction totals and other external services are kept separate from file content. Ads may fund operation of the site, but they do not change tool results or create a paid-download requirement.

Corrections and improvements

Report an incorrect explanation, an unsupported file or an inconvenient workflow through a tool's feedback area or by email. We investigate reproducible cases and update the implementation or the relevant guide.
